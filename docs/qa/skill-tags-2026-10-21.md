# 스킬·폭주·소환수 태그 점검 (v0.323.1)

## 확인한 문제와 수정

| 문제 | 반영 |
| --- | --- |
| 미보유 도감과 적 정보에서 디안/모르페의 소환수 문맥이 빠짐 | 동일 조립기로 쿠로·시로·디모의 현재 성장 근거, 패시브·일반·궁극·폭주를 제공하고 전체 소환수 정보창으로 연결 |
| 소환수 내부의 피해 태그가 주인 피해 태그를 참조할 수 있음 | 기술 구간별 사전을 우선 적용하여 해당 소환수의 능력치·기술로 설명 |
| 일부 폭주 피해·보호막 및 유티 폭주 돌파 태그 누락 | 모르페/데이나 폭주, 타보아/케찰코아틀루스 궁극기, 유티 깃털 문맥 보완 |
| 방어·저항이 서로 달라도 같은 증가량처럼 보일 수 있음 | 각 능력치에서 증가량을 따로 계산. 수치를 누르면 기준·비율·반올림된 증가량·이 효과만 적용한 합계를 설명 |
| 긴 요약이 본문과 겹칠 수 있음 | 요약의 실제 높이를 먼저 측정해 구분선·본문·돌파 블록을 배치 |
| 긴 문장이 한 덩어리로 보이거나 공백 없는 언어가 넘침 | 효과별 문단, 숫자 강조, 실측 글자 줄바꿈. 태그 링크와 기존 줄바꿈·소수점을 보존 |

방어·저항 수치화 대상은 모르페의 드론 연결, 쿠로/시로의 폭주, 모피 코트, 엘라/데이나의 해당 돌파 효과다. 유지 조건·시간·적 1명당 조건은 본문에 유지한다. 공격 속도·감소율 등은 원래 비율 단위를 유지하며 알려지지 않은 적 능력치를 추정하지 않는다. 계산은 표시 능력치를 기준으로 한 해당 효과의 개별 미리보기다. 전투 중 다른 배율이 함께 붙으면 최종 값은 달라진다고 설명한다. 정수 표시의 반올림을 고려하여 산식에는 근삿값 기호를 쓴다.

## 검사

- 12개 언어 × 50종 정의(아군·적·소환수 포함) × 돌파 0~4 × 패시브/일반/궁극/폭주 = **12,000개 모델**의 본문·요약 수치·돌파·중첩 태그 연결 검사 통과. 미해결 변수·NaN·undefined도 검사한다. 모든 레벨/장비 조합을 전수 검사했다는 뜻은 아니다.
- 전체 단위 검사 367파일 실행: 4161개 통과, 1개 건너뜀, 이전 쿠로/시로 설명 형식을 요구하는 기존 테스트 1개 실패. 해당 검증을 서로 다른 방어 101·저항 67에서 +51/+34를 각각 표시하고 능력치 미상 시 비율로 안내하는 계약으로 갱신했다. 이후 관련 4파일 **226개 재검사 통과**. 앞선 글꼴/용어집 포함 집중 검사도 통과했다.
- 실제 Chromium 2편 통과: 미보유 디안 → 쿠로 → 폭주 → 저항 산식, 미보유 모르페 → 디모, 적 디안(공격력 450/주문력 700) → 시로 → 성장 근거 700. 영어 테리사/엘라/모르페/타보아의 긴 설명·조건·돌파 블록이 실제 화면 경계 안에 배치되는지 확인했다.
- 스크린샷: `/workspace/reports/forgarden-skill-tags-2026-10-21/`. 소환수 SD 애니메이션 로딩 완료까지 기다리는 검사는 이번 두 편의 범위에 포함하지 않는다.
- TypeScript·서버 생성·정식 클라이언트 빌드 및 최신 산출물의 일반/QA/test 격리 검사가 통과했다. 마지막 용어집/글꼴 검사 18개도 통과했다. 운영 DB·실제 배포 주소의 반영은 이 로컬 검사와 별개다.
