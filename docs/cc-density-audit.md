# CC 과밀도 점검 시뮬레이션

원정 증강, 일반 스테이지, 레이드, 원정 보스를 공통 전투 엔진으로 검사한다. 별도의 확률 모형으로 스킬을 흉내 내지 않는다. 고정 seed, 실제 평타·궁극기·폭주·한계 돌파·이동·강인함 경로를 사용한다.

## 실행

```sh
# 모든 CC 3종 조합, SR/SSR 8패턴, 공속/시점, 동일 증강 3인 분산
npm run audit:cc -- --matrix --output /tmp/cc-matrix.json --fail-on-risk

# 빠른 점검: 모든 계열 쌍을 포함하는 부분 행렬
npm run audit:cc -- --matrix --quick --output /tmp/cc-quick.json

# 원본 캐릭터: 공속·이속·한계 돌파 0~4·근접/원거리/측면 배치
npm run audit:cc -- --engagement --output /tmp/cc-engagement.json

# 원거리 제공자 셋 ↔ 느린 근접 적: 60초 도발 왕복/공격 공백
npm run audit:cc -- --mobility --duration 60 --output /tmp/cc-mobility.json

# 실제 일반 스테이지 / 레이드 / 원정 보스, 양쪽 모두 점검
npm run audit:cc -- --mode stage --stage 1-10 --targets all --output /tmp/cc-stage.json
npm run audit:cc -- --mode raid --boss koma --targets all --output /tmp/cc-raid.json
npm run audit:cc -- --mode endless --boss pontos --targets all --output /tmp/cc-boss.json

# 특정 파티·레벨·가상 증강 비교
npm run audit:cc -- --mode stage --stage 1-10 --party deina,torika,ella --level 30 --augments tag-taunt-basic@deina --seed example --output /tmp/cc-custom.json
```

`--targets enemy|player|all`, `--duration`, `--seed`, `--party`, `--level`을 지원한다. 증강을 일반 스테이지에 넣는 옵션은 QA 가정이며 실제 플레이 획득 경로를 변경하지 않는다. `--fail-on-risk`를 주면 기준 초과 또는 관측 부족에 종료 코드 1을 반환한다. 도구 실행에 외부 서비스는 필요 없다.

## 실제 집계

- 기절·경직·빙결·수면·공포·광란·날려버림뿐 아니라 **도발**도 CC로 센다.
- 도발 중 실제 표적이 바뀐 뒤, 공격 준비가 끝났는데 강제 표적을 추적하느라 때리지 못하는 구간은 `retarget` 유사 CC로 센다. 도발 종료 뒤에도 첫 적대 공격까지 추적한다. 단순히 이미 걷고 있던 구간 전체를 도발 탓으로 세지 않는다.
- CC 총시간은 상태의 합집합이다. 기절과 수면이 겹쳐도 두 배로 세지 않는다. 종류별 시간은 겹칠 수 있어 합계가 총시간과 다를 수 있다.
- 완전 행동 차단과 표적 제약을 따로 표시한다. 도발 30초는 반드시 완전 행동 불능 30초라는 뜻이 아니다.
- 연속 제어 최장 시간, CC 점유율, 제어 사이 자유 시간, 표적 변경·왕복 횟수, 강제 추적 시간, 첫 적대 공격 시각, 실제 적대 공격 사이 최장 공백을 기록한다.
- 타임라인을 포함한 결과는 적대 공격 시각과 제공자별 실제 증강 발동 시각·재발동 대기·N타 조건도 기록한다. 최초 공속·이속·사거리·공격 간격·돌파 단계도 저장한다.
- 광역/연격의 같은 프레임 다중 적중은 공격 프레임 하나로 센다. 이것은 시전 횟수나 논리적 평타 수와 동일한 지표가 아니다. 반사·지속 피해는 직접 공격으로 세지 않는다.

기본 0.02초 간격으로 관측한다. 0.005~0.05초를 지원하며 판정에는 2스텝 오차를 허용한다. 짧게 끝난 전투는 안전 통과로 숨기지 않고 `insufficient`로 표시한다. 실제 스테이지 기본 관측 최소는 10초, 증강/보스는 20초다. 기준 초과가 이미 있으면 관측 부족보다 실패를 우선한다.

무증강/증강 쌍은 같은 seed·배치를 사용한다. `pairedComparisons`에서 첫 공격 추가 지연, 잃은 공격 프레임, 제어 시간 차이, 추적 시간 차이를 비교한다. 넓은 배치의 원래 이동 비용과 증강이 추가한 비용을 구분하기 위한 비교다. 난수 소비와 후속 전개까지 같다는 보증은 아니다.

## 증강 제어 제한

| 계열 | 평타형 재발동 | 궁극기형 재발동 |
|---|---:|---:|
| 경직 0.15초 / 0.3초 | 1초 | 2초 |
| 기절 0.25초 / 0.5초 | 4초 | 6초 |
| 둔화 | 4초 | 4초 |
| 공포 | 6초 | 6초 |
| 빙결·도발·광란·날려버림 | 8초 | 8초 |
| 수압·졸음·위압 | 10초 | 10초 |

대기는 제공자별이며 카드 설명 **하단**과 태그 팝업이 실제 데이터 값을 읽는다. 수압·졸음·위압은 겹을 올리는 발동부터 대기를 적용한다. 누적 태그의 겹 유지 시간과 최대 겹도 그대로 적용되므로 발동 가능 여부를 피해량과 함께 검토해야 한다.

별도로 대상 하나가 모든 증강 제공자·종류의 회복 시계를 공유한다.

1. 증강으로 새로 생긴 CC 한 번은 상태 위력 증가 후에도 최대 0.6초다. 기존 원본 스킬의 지속시간을 깎지 않는다.
2. 제어 종료 뒤 최소 2.4초 동안 새 증강 제어를 받지 않는다. 원본 스킬 제어도 관측해 증강이 그 끝의 빈틈을 메우지 못하게 한다.
3. 증강 제어를 받은 대상은 **새 적대 평타/공격 궁극기 한 번**을 실행해야 다음 증강 제어를 받을 수 있다. CC 전에 발사한 지연 타격, 지속 피해·반사·아군 공격은 공격 기회로 인정하지 않는다. 그 첫 공격 뒤에도 2.4초를 보장한다.
4. 회복 중 쌓인 N타 조건은 나중에 한꺼번에 방출하지 않는다. 제어가 없는 피해·회복·보호막 태그에는 이 제약을 적용하지 않는다.

따라서 1초 대기 경직도 같은 적에게 세 명이 번갈아 걸어 연속 제어를 만들 수 없다. 다른 적을 때릴 때는 제공자 대기와 그 적의 회복 시계를 각각 확인한다. 공용 회복은 모든 CC 면역이 아니라 **증강 CC 제한**이며 원본 스킬끼리의 기존 제어는 별도 감사 대상으로 남는다. 둔화의 원본 빙결 연계와 파치 폭주의 뇌진탕→날려버림도 증강 경로에서는 이 제어 경계를 지난다.

## 2026-10-25 검수

측정 결과와 재현 입력은 [QA 자료](qa/cc-density-2026-10-25/)에 보관한다. 표적별 제한과 테스트 기준은 서로 다르다. 일반 스테이지/이동 시험은 연속 2초·점유율 40%·자유 구간 0.5초, 증강 접촉 시험은 0.6초·22%·2.4초, 보스는 1초·25%·1초를 기본 경고 기준으로 삼는다. 이를 넘었다는 사실만으로 무한 CC라고 판정하지 않는다.

원본 CC 캐릭터 조합에 공속·돌파를 더한 시험은 기준 초과를 실제로 발견했다. 데이·토리카·엘라의 고공속 사례는 증강 없이 도발 등 CC 상태의 합집합이 30초를 채웠다. 이때에도 적의 직접 공격은 발생했으므로 완전 행동 불능과 구분했다. 원본 제어를 자동으로 약화하거나 경고 기준을 완화해 통과시키지 않았다.

도발 이동 시험에서도 제어 상태가 끝난 뒤의 추적으로 경고가 남는다. 첫 접촉까지의 이동을 포함하는 원자료와 무증강 대비 추가 지연을 함께 확인해야 한다. 실제 적대 공격을 보장하는 런타임 제한과, 이동·원본 제어의 밸런스 경고는 함께 유지한다. 유한 시간의 행렬은 모든 로스터·스테이지·미래 수치의 안전성을 증명하지 않는다. 새로운 태그/돌파를 추가할 때 같은 도구로 재검수한다.

### 최종 관찰값

- 증강 혼합/동일 ID 분산 3,894조건: 기준 초과 0, 관측 부족 0. 연속 제어 최대 0.6초, 점유율 최대 16.6667%, 제어 사이 자유 구간 최소 2.42초. 표적은 30초 동안 최소 16프레임에서 적대 직접 공격을 했다.
- 원본 제어 집중 편성 810조건(405쌍): 무증강 405조건과 증강 405조건 모두 일반 경고 기준 초과. 공속 배율 0.6·1·4, 이속 0.5·1·2, 돌파 0~4, 세 배치와 세 편성을 사용했다. 일반 로스터 전체의 실패율을 뜻하지 않는다. 표적의 적대 공격은 최소 2프레임이었고, CC 상태 합집합은 최악 30초였다.
- 넓은 사거리/느린 근접 도발 36조건(18쌍, 60초): 무증강 경고 0, 증강 경고 8. 최대 합집합 3.7초에는 도발 뒤 추적 이동이 포함된다. 첫 공격의 무증강 대비 추가 지연은 최대 1.14초, 적대 직접 공격은 모든 조건에서 최소 33프레임이었다. 이 8조건을 안전 통과로 바꾸지 않고 추적 지연 검토 대상으로 보관했다.
- 실제 1-10 스테이지와 원정 보스 프리셋은 원본 제어의 자유 구간 경고를 냈다. 레이드는 사망한 아군의 관측 부족을 표시했다. 원자료에 각 대상의 위반 이유·관측 시간이 있다.

태그 팝업의 1초·8초·10초 대기, 0.6초 상한, 공용 회복 안내를 브라우저에서 확인했고, 태그를 눌러도 후보가 선택되지 않았다. 지원 언어 12개의 표와 번역 원고를 함께 갱신했다.

검증: 전체 회귀 396파일·4,735개 통과(기존 건너뜀 1개), 최종 비교/용어/번역 집중 재검사 44개 통과, 타입 검사 및 프로덕션 빌드 통과. CLI의 36개 쌍 비교 출력과 3개 실제 모드 실행도 확인했다.

## 고대 지층

`--mode ancient --floor 120 --equipment ceiling`은 고대 지층 공용 생성 함수와 합법적 기준 룬을 사용한다. `--party`, `--level`, `--duration`, `--targets`도 적용되며 원정 증강 주입은 거절한다. 유대는 현재 기준 파티의 상한 10을 사용한다. 90초 제한을 넘겨 검사하지 않는다.

```sh
npm run audit:cc -- --mode ancient --floor 120 --party pachi,ella,mette --equipment ceiling --targets all --duration 90 --output work/ancient-cc.json
```

현재 편성·시련과 측정 한계는 [고대 지층 보고서](ancient-strata-varied-trials.md), 적의 행동 공백과 제어의 구분은 [적 AI 수정 검증](enemy-utility-ai-fix-2026-10-26.md)을 참조한다. 과거 측정의 CC 경고를 현재 엔진의 안전 통과로 재분류하지 않는다.
