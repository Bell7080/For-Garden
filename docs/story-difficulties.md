# 스토리 확장 난이도

기존 쉬움은 서사와 최초 성장의 경로다. 보통·어려움은 기존 관문을 전투 위주로 다시 도는 독립 진행이며, 배치나 적의 정체성은 바꾸지 않는다. 1-10은 모든 모드에서 코마 정예 한 명이다.

## 해금과 저장

- 보통: 쉬움 4-10. 어려움: 보통 4-10(쉬움도 완료).
- 앞으로 5~8장 이상이 생겨도 4-10 조건을 뒤로 미루지 않는다.
- 기존 ID/클리어/대사 기록은 유지한다. 새 ID는 `normal:1-1`, `hard:1-1` 형태이며 기존 클리어 장부에서 별개로 집계한다. 선택 난이도는 선택 ID에서 복원한다.
- 보통 이상은 전후 대사와 비전투 SUB를 제외한다. 전투 SUB는 그대로 열리고 본편 진행을 막지 않는다. 초회 보상은 모드별 최초 한 번이다. 레이드·원정·이벤트·콘텐츠 해금·패스의 기존 쉬움 조건은 바뀌지 않는다.

## 성장과 보상

`storyDifficultyGrowth`는 챕터/순번으로 공통 기준 레벨·강화를 만든다. 원래 태생 층과 정예/일반/무리 몫을 유지한 채 기존 성장 함수를 통과하며, 강화는 hp/atk/ap/def/res에만 곱한다. 정보창은 실제 최종 수치를, 노드 미리보기는 강화 배수를 표시한다.

| 전환 기준 | 기준 레벨 | 추가 강화 |
| --- | ---: | ---: |
| 보통 1-10 | 56 | 1.00 |
| 보통 4-10 | 60 | 1.20 |
| 어려움 1-10 | 60 | 1.20 |
| 어려움 4-10 | 60 | 1.60 |

인원·보스 패턴이 다른 관문의 실제 전투 시간은 속성·편성에 따라 다르므로 수치가 비슷하다고 동일 승률을 보장하지 않는다. 공통 파티와 같은 장비를 사용한 실전 검수에서 전투 시간·승률·잔여 체력을 비교한다. 지나친 초기 강화는 장비를 갖춘 참조 파티도 전부 막혀 낮췄고, 최종 어려움도 성장·편성으로 완주 가능한 표본을 확인한다.

보통 일반 재화 1.25배·어려움 1.5배, 화석/룬 개수와 입장 비용은 그대로다. 정수 반올림은 기존 재화 지급 규칙을 따른다.

## 구성 참고

[NIKKE 캠페인 가이드](https://www.prydwen.gg/nikke/guides/game-modes-campaign)의 장 클리어 후 상위 모드 해금·강해진 적·추가 보상 구조를 참고했다. 이는 공통으로 쓰이는 구성 패턴이며, 이 게임의 해금 관문·색·성장 곡선·보상 배율은 별도로 설계하고 검수했다.
