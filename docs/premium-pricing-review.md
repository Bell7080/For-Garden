# 프리미엄 가격 검수

기준은 중형 젬 팩(4,900원 / 1,500젬)이다. 대형 젬 팩은 9,900원 / 3,500젬이며 첫 구매 추가 보너스는 표에서 제외했다. 화석·호박석은 개당 젬 300, 기타 재화는 기존 `TRADE_GEM_RATE`, 드링크는 50/100을 적용했다.

패스는 즉시 보상과 기존 진행 마디 전체를, 젬 구독은 30회 일일 수령을 합산했다. 따라서 아래 값은 조건을 모두 채웠을 때의 값이며 진행·출석이 필요한 상품의 가치 배수는 일반 패키지 상한을 적용하지 않는다. 미접속·미진행 몫은 포함되지 않는다. 발굴권·선택 토벌권·소탕권과 광고 제거·3배속은 고정 환산 가치가 없어 배수를 부풀리기 위해 수치를 붙이지 않았다.

젬 구독은 9,900원에 즉시 3,000젬으로 같은 가격의 스토리·레벨 패스 즉시 젬과 맞췄다. 일일 300젬은 광고 제거의 100젬보다 3배이며 30회 수령 총 12,000젬이다. 확정 재화가 약한 발굴 장비·고고학 지원은 즉시 젬 500 → 1,000으로 보강했다. 저가 상품과 계정당 1회 상품의 우대는 기존 기획을 유지했다.
