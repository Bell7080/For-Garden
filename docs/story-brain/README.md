# 스토리 브레인 — 이야기를 짜기 전에 펴는 곳

본편·서브 대사(`src/data/dialogues/`)를 쓰거나 고치기 전에 이 폴더를 먼저 읽고, 고친 뒤에는 이 폴더를
함께 고친다. 대사 파일은 **결과물**이고, 이 폴더는 그 결과물이 서로 어긋나지 않게 붙잡는 **장부**다.

설정의 원본은 여전히 `docs/lore.md`(세계·도시·공멸의 목표)와 `docs/factions.md`(스쿼드·소속)다.
이 폴더는 그 위에서 **이야기가 실제로 어디까지 말했는가**를 기록한다 — 설정 문서는 진실을, 브레인은
플레이어가 지금 아는 것을 적는다. 둘이 갈리면 설정 문서가 맞고, 브레인은 "아직 말하지 않음"으로 둔다.

| 파일 | 무엇을 적나 |
| --- | --- |
| [craft.md](craft.md) | 웹소설 작법 원칙, 무대 문법(퇴장·목소리·장면 연출), 반복 금지 목록 |
| [world.md](world.md) | 세계와 시간선, 비밀의 공개 단계(공개·암시·숨김) |
| [characters.md](characters.md) | 인물마다 바라는 것·필요한 것·숨긴 것·말버릇·지금 상태 |
| [relationships.md](relationships.md) | 관계 장부 — 인연·호감도·적대·상하, 장마다 바뀐 기록 |
| [plot.md](plot.md) | 장별 줄거리, 장 끝 갈고리, 인물 아크의 진행표 |
| [threads.md](threads.md) | 떡밥 장부 — 깐 곳과 거둔 곳 |
| [subs.md](subs.md) | 서브 이야기의 작은 주제와 본편과의 연결 |

## 쓰는 순서

1. **plot.md**에서 그 관문이 장 안에서 맡은 일(압력·해소·갈고리)을 확인한다.
2. **characters.md**와 **relationships.md**에서 등장인물의 지금 상태와 서로의 거리를 확인한다.
   이번 장면이 그 거리를 바꾸는가? 바꾼다면 왜 지금인가?
3. **threads.md**에서 이 장면이 깔 떡밥·거둘 떡밥을 고른다. 거두는 떡밥은 깐 자리보다 반드시 뒤다.
4. **craft.md**의 무대 문법과 반복 금지 목록으로 연출을 고른다.
5. 대사를 쓴다(말투는 `docs/character-voice.md`).
6. 쓴 뒤 **relationships.md의 변화 기록**과 **threads.md**를 고치고, 새로 공개한 비밀은 **world.md**의 단계를 올린다.

## 지키는 선

- **Garden 상층부의 정체와 목적을 단정하지 않는다**(lore). 「위」는 명령을 내리는 목소리까지만이다.
- **적은 연구원을 미워하지 않는다.** 공멸은 연구원을 해칠 대상이 아니라 손에 넣고 싶은 사람으로 대한다.
- 플레이어(연구원)의 성별을 정하지 않는다. 연구원은 대사가 없다 — 반응은 주변 인물과 지문이 말한다.
- 렐릭은 모두 여성형 인격이다. 지문에서 그녀/그를 쓰지 말고 이름이나 묘사로 가리킨다.
