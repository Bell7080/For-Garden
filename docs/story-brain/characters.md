# 인물 — 바라는 것·필요한 것·숨긴 것

형식: **바람**(want, 겉으로 쫓는 것) / **필요**(need, 진짜로 얻어야 하는 것) / **거짓**(스스로 믿는 틀린 믿음) /
**목소리**(말버릇, 상세는 `docs/character-voice.md`) / **지금**(7장 끝 기준 상태).

## 연구원 일행

### 연구원(플레이어)
- 대사 없음. 반응은 동료와 지문이 말한다. 성별·외모를 정하지 않는다.
- 공멸에게는 「손에 넣어야 할 사람」, 일행에게는 「대장님·마스터·연구원님」. 호칭이 곧 관계다.
- 지금: 자신이 자물쇠를 풀었다는 것을 막 알았다. 왜인지는 모른다.

### 토리카 (쁘띠 로그, 호위)
- 바람: 대장님을 지키는 첫 번째 호위가 되는 것. / 필요: 혼자 다 막지 않아도 된다는 것.
- 거짓: 「내가 앞에 서면 아무도 안 다친다」. / 목소리: 밝은 해요체, 「대장님!」.
- 지금: 6장 추락으로 대장님을 놓쳤다가 7-7에서 되찾음 — 다시 놓칠까 봐 더 붙는다.

### 도디 (쁘띠 로그, 기록병)
- 바람: 대장님의 모든 것을 일지에 남기는 것. / 필요: 기록이 사람을 지킨다는 것을 믿는 것(2-4 벽의 번호를 옮겨 적음).
- 목소리: 들뜬 해요체, 「대장님」. 관찰력이 좋다(손자국, 발자국).

### 파루아 (쁘띠 로그, 후위)
- 말이 적고 먼저 본다. 「…」로 시작하는 짧은 보고. 남의 상처를 먼저 보는 눈(2-5 아모의 표식).

### 렉시아 (앱솔루트 팽)
- 바람: 마스터 앞에 서는 여왕. / 필요: 힘으로 안 되는 일도 있다는 것. / 목소리: 당당, 마스터.
- 장치: 문을 뽑는다 — 이제 반복 금지(craft 6).

### 엘라·파치·아크·유티 (앱솔루트 팽)
- 엘라: 방벽, 존댓말 「연구원님」, 시말서. 파치: 머리로 벽을 연다, 「보스」. 아크: 므하하, 「마스터」. 유티: 말을 더듬으며 호칭을 고친다.

### 스피나·루카·델로피·마키·데이·모사나 (나이트 기어)
- 그늘에서 길을 여는 무리. 스피나: 조용히, 오래 머무르지 말라. 루카: 앞길 정찰, 짧은 반말. 델로피: 마술 장난, 짠~.
  마키: 의사, 「~냥」. 데이: 낙서, 직감이 빠름(몰이를 처음 꿰뚫음). 모사나: 물속 줄, 「당신」.

### 스테라·켄토·케리스·이르나·슈테·모르페 (시그널 아이)
- 관측과 통신. 스테라: 바람을 읽음, 「선배」(켄토를). 켄토: 키 콤플렉스, 앞에서 받는 사람. 케리스: 사서, 기록을 읽음.

### 노도니아·테리사·안카·매디·메론 (사일런트 룬)
- 노도니아만 연구원을 「아가」라 부른다. 테리사: 수녀, 존댓말, 바늘땀. 안카: 졸린 경계, 「연구원 씨」.
  매디: 냉방, 「연구원 씨」. 메론: 얼굴을 그려 기억한다.

## 공멸

### 코마 (테러조 간부, 072)
- 바람: 명령을 끝내 「실패작」이라는 말을 듣지 않는 것. / 필요: 자기가 정할 수 있다는 것.
- 거짓: 「번호를 지우면 명령도 지워진다」(7-9). 실제로는 카르가 「다시 적는다」.
- 목소리: 마침표로 끊는 단문, 「…」. 감정은 행동으로만(표식을 닦는다, 사원증을 돌려준다).
- 아크: 명령 수행(1장) → 미끼임을 앎(2장 서브) → 번호를 지움(3-10) → 명령 거부(7-9) → 연구원 곁에서 걷는다(7-10).
- 지금: **자기가 연구원을 아래로 데려왔다는 사실의 무게.** 「손이 아니라 당신이었다」는 사실은 코마가 지켜 온
  「손만 대지 않으면 된다」는 선을 무너뜨린다 — 8장의 죄책감 갈고리.

### 토비·아모·리파 (테러조 삼인조)
- 토비: 큰소리, 정의감, 「다음엔 진짜 이긴다」. 아모(001, 최초의 호문쿨루스): 두건, 조용, 토비를 챙긴다. 리파: 재미, 관찰.
- 바람: 코마에게 인정받는 것 → (2-10) 스스로 정하는 것. 2-10에서 연구원을 따라가기로 했다가 3-1에서 회수조에게 끌려간다.
- 지금: 회수조 감시 아래. 몸은 적, 마음은 반쯤 연구원 쪽(4-3, 4-3 서브).

### 이카닉시아 (회수조 간부)
- 바람: 연구원을 정해진 곳까지 「모셔 가는」 것. / 거짓: 다 계획대로다. / 목소리: 경어, 「후훗」, 「서두를 이유는 없다」.
- 비밀: 그 느긋함은 몰이였다 — 쫓는 척 아래로 밀었다(7-5에서 본인 입으로 확인).
- 지금: 카르 해방으로 「줄을 서야 하는」 처지(6-7). 자기 계획이 끝난 뒤의 자리가 불안하다.

### 아트라 (회수조 부간부)
- 더듬는 말, 소매로 얼굴을 가림, 「선배」(코마). **목록**에 마음에 드는 이름을 적는다 — 지우지 않는 것이 그녀의 저항.
- 지금: 회수조의 일(이름 지우기)과 자기 목록 사이에서 갈라짐(7-6 서브).

### 네우리·펄시·미르 (회수조)
- 네우리: 장부, 「후훗… 어흠」, 경어. 7-6 서브에서 「기록 손상」이라는 작은 거짓말로 처음 편을 듦.
- 펄시: 깜짝 선물, 재미. 미르: 점수를 모은다 — 칭찬 한 번이 바람(3-3 서브).

### 마가사·노아·라자 (감금조)
- 마가사: 식사 당번 간부, 다정한 말투로 무서운 말(「재료」). 식구를 먹인다. / 노아: 가장 겁 많은 간부, 「오지 마」.
  / 라자: 서열을 매일 긋는 고참, 「앞에 서는 놈이 나른다」.
- 공통 바람: 부대장을 꺼내 위로 올라가는 것. 지금: 카르를 따라 위로.

### 카르 (부대장)
- 최하층에 묶여 있던 가장 위험한 개체. 짧고 무거운 말, 「072」라고 부른다. 이름 칸만 이름이었던 유일한 수감자.
- 바람: 풀려나는 것, 대장들에게 돌아가는 것. / 지금: 풀렸다. 「연구원은 다음에 데려간다」 「지운 번호는 내가 다시 적는다」.

### 궁니르·철갑 (대장, 기가노토·티타노)
- 목소리만. 7-10 끝 방송이 첫 언급. 직접 등장은 아껴 둔다.
