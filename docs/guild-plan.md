# 길드 구현 계획

v0.377.0 기준(2026-10-28)으로 다시 정리한 길드 계획이다. 예전 설계 원본(`/mnt/project-files/guild/proposal.md`)은
남아 있지 않아 이 문서가 그 자리를 잇는다. 규칙 자체는 `CLAUDE.md`의 「길드」 절과 `src/core/guild*.ts`가 갖고,
이 문서는 **무엇이 끝났고 무엇이 비었는지**와 다음 순서만 적는다.

## 3. 길드 상점 — v0.376.0 구현

응태 승인(2026-10-28): 구성안대로 구현하되 **만능 파편은 팔지 않는다**. 표와 근거는 `VERSION.md` v0.376.0,
상품 정의는 `GUILD_SHOP_PRODUCTS`(`src/core/guild.ts`)가 갖는다.

- **주간**: 골드 5,500(20) · 치즈케이크 24(20) · 에너지 드링크(90) · 희귀 룬(450, 주 1)
- **월간**: 화석 1(600, 월 1)
- **길드 레벨**: 길드 보급(160, 주 1, 길드 Lv.10) — Lv10 혜택 「상점 4번째 칸」이 이 칸이다

수입 모델(주): 출석 45 + 수호전 70~280 → 보통 ~210 · 열심히 ~325. 시세 코인 1 = 젬 0.5. 주간 한도 합 990이라 다 살 수 없다.

**넣지 않는 것**: 만능 파편(응태 결정) · 원석(고고학 75% 규칙) · 젬·호박석·미지핵.

**남은 것**
- 운영 DB에 `20261110000000_guild_shop_tabs.sql` 적용(마이그레이션 → 서버 → 클라이언트). 적용 전에는 새 세 상품을 못 사고 레벨 탭이 잠겨 있다.
- 길드 꾸미기(프로필 테두리·수식어, 1회 구매) — 서버에 꾸미기 지급 경로부터 만들어야 한다.
- 전용 점원 원화·무대 배경(2장 목록) → `SHOP_STAGE_PRESENTATION.guild`의 점원·배경·대사만 바꾼다. 월간·레벨 탭 전용 대사도 이때.
- 길드전 코인 수급이 붙으면 주간 한도 합을 수입 대비 다시 잰다.
