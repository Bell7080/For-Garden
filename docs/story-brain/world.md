# 세계 — 플레이어가 지금 아는 것

원본 설정은 `docs/lore.md`. 이 표는 **본편 대사가 어디까지 말했는가**만 적는다.

## 무대

- **이터널 시티 제1지부** — 본편의 무대. 살아남은 지부. 1장 외곽 → 2장 생산 회랑·잔해 지구 → 3장 회수 구간
  → 4장 합동 추격 선로·사령실 → 5장 지하 감금동 → 6장 감금동 상층 회랑 → 7장 최하층 구속실.
- **방향은 늘 아래다.** 1장에서 도시로 들어가려던 일행은 2장 끝 구멍, 4장 끊어진 승강기, 6장 꺼진 바닥을 거쳐
  계속 아래로 떨어진다. 5장 끝에서 데이가 깨닫듯 **그 하강은 몰이였다**(threads: 몰이).
- 제2·제3지부(수장)·폰토스는 원정이, 바깥 도시들은 교류가 맡는다. 본편에서 풀지 않는다.

## Apex — 도시 안의 민간 대기업

원본은 `docs/lore.md` §1.1.1. **상층부(Garden)와 다른 주체다** — 상층부가 바깥에서 예산·인가를 쥔다면, Apex는 도시 **안**에서
물건을 파는 회사다. 둘을 한 덩어리로 쓰지 않고, Apex에 음모를 얹지 않는다(「도시가 아직 사람이 사는 곳」이라는 것을 말하는 자리다).

| 브랜드 | 업종 | 누가 / 어디서 나왔나 |
| --- | --- | --- |
| **A-LAB24** | 편의점 | 점원 **오비**(견습 알바생). 상점 화면 = 중앙 연구소 1층 지점. 본편 1-9에서 토리카가 유니폼을 알아본다 |
| **블렌딩A** | 찻집 | 렉시아 애착 이야기(마스터가 맛있다 한 홍차의 한정판), 테쿠의 궁극기 이름(「블렌딩A - 말차 99%」) |
| **A-CLEAN** | 청소 용역 | 아르테(에이스 신입). 애착 이야기·일지에서 이름을 댄다 |

- **플레이어가 지금 아는 것**: 「A-LAB24」 상호(1-9)뿐이다. **「Apex」라는 회사 이름은 어떤 대사에도 아직 나오지 않는다** —
  브랜드 셋이 한 회사라는 것은 설정에만 있다. 처음 이름을 꺼낼 자리를 정하면 여기 적는다.
- 브랜드를 「Apex 매장」으로 뭉뚱그리지 않는다. 어느 매장인지 정하지 않은 가게(디안의 늑대 카페)를 Apex에 붙이지 않는다.
- 겹침 주의: 테쿠 애착 이야기 4장은 자기가 맞춘 블렌딩을 「에이(A)」라 이름 지었다고 한다 — 찻집 상호 「블렌딩A」와 이름이 같다.
  지금은 「브랜드를 따라 지은 이름」으로 읽어 둔다. 둘의 관계를 대사로 풀 때 어긋나지 않게 이 줄부터 고친다.

## 시간선

| 시점 | 사건 |
| --- | --- |
| 부임 전 | 복제 연구원 전원 철수. 렐릭 프로젝트 방치. 실패 개체는 폐기 표식(점)을 달고 처리장·구멍으로 |
| 오프닝 | 연구원 수송 열차를 공멸 테러조가 폭파(명령: 「방주째로 떨어뜨려」) |
| 1장 | 외곽 탈출, 코마와 첫 대면, 렉시아 합류 |
| 2장 | 폐기 표식의 의미, 아모의 번호, 회수조 등장, 삼인조가 스스로 연구원을 따라오기로 |
| 3장 | 회수조가 삼인조를 끌고 감. 코마가 「내 번호를 지웠다」 |
| 4장 | 합동 추격, 승강기 추락. 「072. 감금동을 열어라」 |
| 5장 | 감금동. 수감 명단(번호와 무게). 마가사의 폭로: 맨 아래 자물쇠는 사람 손으로 |
| 6장 | 감금조와의 대치. 카르의 이름. 바닥 붕괴 |
| 7장 | 사일런트 룬이 연구원을 구함. 카르 해방. 자물쇠는 손이 아니라 **연구원 자신**에 반응했다 |
