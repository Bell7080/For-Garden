# 상점과 교류 교환소 진입 계약

일반 상점과 교류 교환소는 이름이 비슷해도 서로 다른 기능이며, 로비에서 중복 진입점을 만들지
않는다.

| 기능 | 로비의 유일한 진입점 | 최종 화면 | 카탈로그 경계 |
| --- | --- | --- | --- |
| 일반 상점 | 왼쪽 콘텐츠 레일의 **상점** | `ShopScene` | `shop` 상품만 표시 |
| 교류 교환소 | 하단 **교류** | `InteractionScene`의 **교환소** 버튼 | 교류 표본 교환 제안만 표시 |

재화 안내에서 교환 기능으로 이동할 때도 로비 위의 별도 무역 팝업을 열지 않는다. 안내 액션은
`InteractionScene`을 시작하고 같은 교환소 진입 메서드를 호출한다. 따라서 일반 상점은 상점 레일,
교류 교환소는 교류 씬 안의 버튼이라는 한 경로씩만 유지된다.

## 임시 자산 추적

일반 상점의 점원은 아직 최종 확정되지 않은 토리카 Puppet이다. 교체 대상은
`src/data/shopPresentation.ts`의 `SHOP_MERCHANT_ASSET` 한 상수로 격리되어 있으며, 최종 점원 자산이
도착하면 씬 배치나 로딩 코드를 복제하지 않고 그 값만 교체한다.
