# 수집형 RPG로서 비어 있는 것

세계관(`docs/lore.md`)과 현재 구현(`README.md`)을 비교해 부족한 축만 간결하게 정리한다.
1인 개발 범위를 전제로, **없으면 장르가 성립하지 않는 것**부터 위에 둔다.

## A. 지금 당장 없으면 장르가 안 되는 것

| 축 | 현재 | 필요한 것 |
| --- | --- | --- |
| **저장** | 메모리뿐 | 진행도 영속화. 껐다 켜면 초기화되는 수집형은 성립하지 않는다 |
| **희귀도** | 없음 (전 렐릭 동일 풀) | ★ 등급 + 등급별 확률 + 픽업. 뽑기의 감정 곡선이 여기서 나온다 |
| **중복 처리** | 없음 | 중복 → DNA 숙련도(이미 0~5 존재) 또는 재화 환원. 뽑기 지속의 근거 |
| **천장** | 없음 | 누적 카운터 보장. 과금·신뢰 설계의 최소선 |
| **육성 재화 소비처** | 레벨·Heart Gem 계산식만 있음 | 레벨업/승급에 쓰는 재료와 그 획득처(일일 던전 등) |
| **일일 루프** | 없음 | 스태미나 또는 일일 임무. 매일 켤 이유 |

## B. 세계관이 이미 요구하는데 시스템이 없는 것

- **호감도 / 유대감**
  세계관의 핵심 장치("주인공의 유대감이 야성을 붙잡는다")가 시스템으로 존재하지 않는다.
  지금 `애착 렐릭`은 로비 배치용 플래그일 뿐이다. 유대 수치 → 대사 해금 → 소폭 버프의
  가장 단순한 형태부터 붙이는 게 좋다. **이 게임의 차별점은 여기다.**
- **야성 게이지**
  스탯 `ferocity`가 이미 있지만 서사적 의미가 없다. 예: 전투 중 야성이 차오르면 화력이
  오르고 이성이 깎이며, 특정선을 넘으면 통제 불능(아군 오사·강제 폭주). 유대감으로 감쇠.
  **리스크-리턴 하나만으로 전투에 정체성이 생긴다.**
- **스토리 전달 수단**
  오프닝 열차 시퀀스를 실행할 대사/연출 시스템이 없다. 스탠딩 + 텍스트 박스 + 선택지
  수준의 최소 비주얼 노벨 레이어면 충분하다. 선택지는 유대감에 연결한다.
- **번호 · 프로젝트 네임**
  001(아모), 072(코마), 철갑, 궁니르처럼 개체번호가 설정에 있다. 도감에 번호와 발굴 기록을
  넣으면 "고고학" 테마가 UI에서 살아난다.
- **공멸 진영**
  적 렐릭 3종이 있지만 진영 개념이 없다. 스테이지 지도에 공멸 습격 이벤트를 놓으면
  세계관과 콘텐츠 루프가 붙는다.

## C. 운영 컨텐츠 (30종이 차면 필요)

- 스토리 챕터 / 이벤트 상시전 / 무한 도전(랭킹)
- 비동기 방어전은 이벤트·기본 경제 안정 이후의 별도 마일스톤으로만 진행한다.
  서버 권위 스냅샷과 재현 검증 방식은 [`asynchronous-arena.md`](asynchronous-arena.md)를 따른다.
- 상점 (재화 교환 · 스킨) — 로비에 자리만 있고 비어 있다
- 우편, 프로필, 도감 완성도 보상
- 파티 프리셋, 자동 전투 · 소탕

## D. 미소녀 수집형에서 흔히 기대되는데 아직 없는 연출

- 뽑기 연출 (발굴 → 화석 갈라짐 → 등급 섬광). 지금은 결과만 나온다
- 획득 시 첫 대면 대사 / 로비 터치 반응
- 스킨·의상, 보이스, 캐릭터 테마 BGM
- 로비 렐릭의 시선 추적, 대기 모션 다양화 (PuppetForge로 가능)

## 권장 순서

1. **저장** → 2. **등급·중복·천장** → 3. **유대감 + 야성 게이지** (차별점) →
4. **최소 대사 시스템으로 오프닝 구현** → 5. 일일 루프 → 6. 상점·도감 등 운영 컨텐츠

1~2는 없으면 게임이 아니고, 3~4는 이 게임이 다른 수집형과 달라지는 지점이다.
5 이후는 렐릭 30종과 아트 파이프라인이 자리 잡은 뒤에 붙여도 늦지 않다.
