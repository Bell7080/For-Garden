# 첫 로그인·진입 입력 검수 (v0.324.1)

- 공개 설정과 ping을 함께 기다리던 경계를 분리했다. ping 지연으로 이미 도착한 초기화 세대를 버리지 않는다.
- 원격 빌드는 설정 미확인 시 인증 전 재조회한다. 세대 확인→기존 세션 확인→인증→별도 진입 탭 순서를 지킨다. 실제 세대 변경은 boot로 돌아가며 페이지 reload는 사용하지 않는다.
- 인증 성공 콜백은 진입 문구만 표시한다. 인증 전 시작된 포인터·손 떼기 단독·다른 포인터·중복 이벤트는 진입할 수 없다. 명시적인 새 pointerdown→pointerup만 소비한다.
- 원격 main의 저장 복구·계정 전환 보호 변경 3건도 통합했다. 원정 보상 테스트에 추가된 알림 매니저 대역을 반영했다.

## 확인

- 초기 설정 ping 정체/설정 시간 초과 후 재시도, 초기화 세대 변경, 늦은 이전 씬 응답, 인증 연타, 입력 소유권 관련 20개 단위 검사 통과.
- 전체 단위 검사 377개 파일 중 376개 통과, 원정 팝업 테스트의 누락된 알림 의존성 1건은 수정 후 개별 재검사 통과. 최종 합계 4,474개 통과·1개 기존 건너뜀.
- 모바일 타이틀 6경로: 게스트·구글·애플·이메일·아이디 가입·아이디 로그인 모두 성공 후 타이틀 대기, 손 떼기만으로 진입 금지, 새 탭 후 로비 진입 확인.
- 인증 응답은 격리 대역을 사용했다. 실제 Google/Apple OAuth 계정과 운영 DB에 로그인하거나 사용자 데이터를 변경하지 않았다.
- 타입 검사·프로덕션 빌드·서버 번들 생성 통과. SQL 변경 없음. 서버/클라이언트를 함께 배포한다.
