# 스토리 확장 난이도 검수 — v0.325.0

## 확인한 동작

- 쉬움/보통/어려움 선택창과 노랑/주황/빨강 지도 톤.
- 쉬움 4-10 → 보통, 보통 4-10 → 어려움 해금. 새 장이 추가돼도 이 조건을 고정한다.
- 모든 원본 전투의 캐릭터·인원·배치·정예 역할·전투 SUB 보존. 각 난이도 1-10은 코마 정예 한 명.
- 보통 이상은 서사 SUB와 전후 대사 제외, 같은 난이도 안에서만 다음 관문으로 이동.
- 서버 입장/전투 발급/정산의 잠금 검증, 별도 초회 기록과 보상, 기존 저장 장부를 통한 재접속 복원.
- 실제 서버 발급 적과 클라이언트 미리보기 적 데이터의 일치.

## 검증

- 기존 난이도·저장·번역 회귀 115개 통과.
- 전체 단위 379개 파일 실행. 처음 실패한 결과창 대역 2개 파일, 번역 용어 예외 1개 파일, 조정 전 난이도 표본 1개 파일을 보완한 뒤 새 서버 발급 검사까지 포함해 관련 5개 파일 21개 검사 통과. 그 외 375개 파일은 전체 실행에서 통과했다.
- 타입 검사·최종 프로덕션 빌드·서버 번들 생성 통과. 기존 큰 번들 크기 안내 외 빌드 오류 없음.
- Pixel 7 모바일 한 편 통과: 잠긴 어려움 선택 불가 → 보통 전환 → 코마 정예 확인 → 서버 해금 영수증 → 축하창 → 어려움 전환 → 새로고침 → 어려움 선택/진행 복원.
- 개발 서버 HMR 후 직접 import한 검사 세션과 화면 세션이 갈라진 간섭은 소스가 고정된 새 서버에서 제거하고 재검증했다. 운영 인증이나 DB를 변경하지 않았다.

## 전투 표본

레벨 60·돌파 V, 전설 룬 3부위의 합법적인 주 옵션 상한에 해당하는 HP/공격/방어 성장만 사용했다. 룬 특성/유대는 제외했다. 같은 5개 파티 × 5개 관문 × 3개 시드, 총 75판이며 궁극기도 실제 코어 경계로 사용한다.

| 파티 | 보통 4-10 | 어려움 4-10 |
| --- | --- | --- |
| 토리카/렉시아/루카 | 3/3 승리, 평균 9.7초, 잔여 HP 65% | 3/3 승리, 평균 13.3초, 잔여 HP 43% |
| 엘라/마키/스텔라 | 3/3 승리, 평균 11.6초, 잔여 HP 64% | 0/3 승리 |
| 노도니아/스피나/메테 | 3/3 승리, 평균 11.7초, 잔여 HP 57% | 0/3 승리 |
| 토리카/디안/루카 | 3/3 승리 | 1/3 승리 |
| 엘라/디안/스텔라 | 3/3 승리 | 1/3 승리 |

난이도 차이가 단순 표시가 아니라 체력 손실·전투 시간·승률에 나타나며, 어려움 마지막 관문도 적절한 성장과 편성으로 완주할 수 있음을 확인했다. 이 표본은 모든 룬 특성·수동 타이밍·편성의 승률을 보장하지 않는다. 구성과 저장 호환성은 `docs/story-difficulties.md`에 기록했다.
