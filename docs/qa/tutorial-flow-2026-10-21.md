# 초반 튜토리얼 연결 (v0.323.0)

## 진행

| 시점 | 안내 / 저장 |
| --- | --- |
| 1-1 후 | 광장 출격 → 스토리 → 1-2 입구 |
| 1-2 편성 | SD 자리 이동 → 편성 렐릭 길게 눌러 정보 확인 → 출전. 이동/정보 확인은 건너뛰기 가능하며 편성 저장은 기존 출전 API를 따른다. |
| 1-2 완료 | 후 대사를 보존하면서 광장 복귀 → 렐릭 탭 → 토리카 자동 선택 → 일반 강화 `feed` → 강화 버튼 길게 누르기 → 1레벨 즉시 강화 `feedLevel` → 광장 복귀 |
| 1-3~1-5 | 연출 스킵 → 배속 → 기여도. 각 관문 초회 클리어 때 기존 서버 경계가 한 칸씩 연다. |
| 1-5 완료 | 후 대사 → 광장 → 복원 연구 개방 안내 → 기존 지원 화석 8개 1회 → 첫 복원 10회 |

강화/연구가 실패하면 진행 칸을 완료하지 않는다. 안내는 다른 창 뒤에서 입력을 막지 않고 대기하며 씬 종료 시 폐기한다. 첫 연구는 결과/비용과 튜토리얼 완료가 같은 서버 저장에 포함되므로 별도 완료 요청 유실로 재연구를 요구하지 않는다. 지원품은 기존 서버 보상 표를 그대로 사용하며 새 보상을 추가로 중복 지급하지 않는다.

## 저장 이전 / 배포

v51은 `ultimate → auto → feed → feedLevel → presentation → speed → contribution → gift → pull` 순서다. v50에서 연출 안내까지 이미 지난 계정은 새 강화 두 칸을 완료 처리한다. `gift/pull` 완료를 보존하므로 지원품을 다시 주지 않는다. 1-2까지만 지난 계정은 토리카 강화에서 이어 간다. 저장 검증/자동 이전은 서버·클라이언트의 SaveManager가 공유한다. 별도 SQL은 없으며 생성된 api/game.js와 클라이언트를 함께 배포한다.

## 검증 범위

- 실제 Chromium + 엄격한 서버 handleGameCall + 독립 상태 저장 fixture: 광장/1-2 이동·편성 드래그·길게 눌러 정보 확인, 토리카 일반/즉시 강화의 확정 단계·레벨 저장, 연구 개방/지원 화석 8개/실제 10회 연구의 비용·획득·완료 저장. 세 흐름 통과.
- 브라우저 준비 상태는 각 구간 직전의 정상 저장이다. 이 검사가 1-1~1-5 전투와 모든 대사를 연속 플레이했다는 뜻은 아니다. 결과 화면의 후 대사/광장 복귀 선택은 별도 제품 클래스 실행 검사로 확인한다.
- 저장 v50 왕복, 이미 받은 지원품 중복 호출, 첫 연구 저장 실패 원자성, 기존 서버 단계 순서/보상 상한, 12개 언어·글꼴 검사를 포함한다.
