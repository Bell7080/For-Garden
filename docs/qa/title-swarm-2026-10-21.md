# 타이틀 인증·물량전·디안 재소환 검수 (v0.322.1)

## 변경과 근거

- 타이틀 인증 성공 콜백이 버튼만 지우고 추가 터치를 기다리던 경로를, 같은 계정의 서버 진행 연결 후 직접 진입하도록 변경했다. ID/이메일/소셜 공통 잠금은 언어 변경에도 유지하며 씬 세대로 늦은 응답을 걸러낸다.
- 쓰러진 적은 최종 사망 비행·소멸 tween만 재생하고 뼈대 계산을 중단한다. 부활은 동작을 다시 연다. 숨긴 캐릭터도 스키닝을 중단하고 숨긴 시간을 따라잡지 않는다.
- 정점 버퍼를 매 draw 재할당하던 것을 최초 할당 + 새 자세의 bufferSubData로 바꾸었다. 정지 자세·추가 카메라는 전송을 반복하지 않으며 컨텍스트 복구 시 다시 올린다.
- 일반/궁극기/패시브/폭주/회복/사망의 파편을 60~75% 줄이고 종류별 emitter의 생존/풀 상한을 24로 정했다. 기존 텍스처 공유·URL 진행 중 로딩 중복 방지·파싱 worker·효과 풀은 유지한다.
- reviveView가 배율을 1로 초기화한 뒤 다음 syncViews에서 복구하던 경로를 수정했다. 안내가 코어를 멈춰도 소환 즉시 정상 높이·위치·방향을 적용한다.

## 검증

- 실제 Chromium ID 로그인/회원가입: 인증 1회, 추가 터치 없이 로비 진입, ID 입력창 소멸 (2편 통과).
- 실제 Chromium 치즈케이크 cake-8: 적 15명 + 디안/토리카/메테와 소환수의 로딩, 재소환 전후 배율 일치, 사망 후 정점 갱신 0회, 재소환 후 정지 해제 (1편 통과).
- 제품 클래스 실행 검사: 인증창 연타/언어 재구성/취소/이전 씬 응답, 숨김·사망·재개 시간, GPU 최초 할당/변경 자세/컨텍스트 복구, 코어 갱신 전 소환 배치. 관련 60검사 통과.
- 서버 전투 규칙·고정 시간 스텝·배속·데미지·보상·DB 구조는 변경하지 않았다.

이 실행 환경은 소프트웨어 WebGL이다. 이번 검사는 제거된 작업과 기능 회귀를 확인하며 모바일 실기기의 FPS 개선율을 의미하지 않는다. GPU batching 재설계나 살아 있는 전투 캐릭터의 애니메이션 프레임 생략은 적용하지 않았다. 특히 PuppetForge의 단일 update는 물리 적분과 모션 시간을 함께 진행하므로 임의 제한은 모션·서버 시간 차이를 낳을 수 있다.
