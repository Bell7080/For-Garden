# 초반 튜토리얼 연결 (v0.323.0)

## 진행

| 시점 | 안내 / 저장 |
| --- | --- |
| 1-1 후 | 광장 출격 → 스토리 → 1-2 입구 |
| 1-2 편성 | SD 자리 이동 → 편성 렐릭 길게 눌러 정보 확인 → 출전. 이동/정보 확인은 건너뛰기 가능하며 편성 저장은 기존 출전 API를 따른다. |
| 1-2 완료 | 후 대사를 보존하면서 광장 복귀 → 렐릭 탭 → 토리카 자동 선택 → 일반 강화 `feed` → 강화 버튼 길게 누르기 → 1레벨 즉시 강화 `feedLevel` → 광장 복귀 |
| 1-3~1-5 | 연출 스킵 → 배속 → 기여도. 각 관문 초회 클리어 때 기존 서버 경계가 한 칸씩 연다. |
| 1-5 완료 | 후 대사 → 광장 → 복원 연구 개방 안내 → 기존 지원 화석 8개 1회 → 첫 복원 10회 |

강화/연구가 실패하면 진행 칸을 완료하지 않는다. 안내는 다른 창 뒤에서 입력을 막지 않고 대기하며 씬 종료 시 폐기한다. 첫 연구는 결과/비용과 튜토리얼 완료가 같은 서버 저장에 포함되므로 별도 완료 요청 유실로 재연구를 요구하지 않는다. 지원품은 기존 서버 보상 표를 그대로 사용하며 새 보상을 추가로 중복 지급하지 않는다.

## 저장 이전 / 배포

v51은 `ultimate → auto → feed → feedLevel → presentation → speed → contribution → gift → pull` 순서다. v50에서 연출 안내까지 이미 지난 계정은 새 강화 두 칸을 완료 처리한다. `gift/pull` 완료를 보존하므로 지원품을 다시 주지 않는다. 1-2까지만 지난 계정은 토리카 강화에서 이어 간다. 저장 검증/자동 이전은 서버·클라이언트의 SaveManager가 공유한다. 별도 SQL은 없으며 생성된 api/game.js와 클라이언트를 함께 배포한다.

## 검증 범위

- 실제 Chromium + 엄격한 서버 handleGameCall + 독립 상태 저장 fixture: 광장/1-2 이동·편성 드래그·길게 눌러 정보 확인, 토리카 일반/즉시 강화의 확정 단계·레벨 저장, 연구 개방/지원 화석 8개/실제 10회 연구의 비용·획득·완료 저장. 세 흐름 통과.
- 브라우저 준비 상태는 각 구간 직전의 정상 저장이다. 이 검사가 1-1~1-5 전투와 모든 대사를 연속 플레이했다는 뜻은 아니다. 결과 화면의 후 대사/광장 복귀 선택은 별도 제품 클래스 실행 검사로 확인한다.
- 저장 v50 왕복, 이미 받은 지원품 중복 호출, 첫 연구 저장 실패 원자성, 기존 서버 단계 순서/보상 상한, 12개 언어·글꼴 검사를 포함한다.


## 2026-10-22 보완 (v0.326.2)

- 연구소는 1-5 클리어 조건으로 잠근다. 하단 탭은 고고학과 같은 자물쇠/조건 문구/개방 연출을 쓰고, 직접 씬 진입과 서버 연구 요청도 차단한다. 1-5 후 개방 안내 → 화석 8개 보급 영수증 → 첫 복원 10회 순서를 유지한다. 스테이지 자체 초회 화석은 별도이며, 보급은 `gift` 멱등 기록으로 한 번만 지급한다.
- 전투 안내는 쉬움 1-1 궁극기, 1-2 자동, 1-3 연출, 1-4 배속, 1-5 기여도로 고정한다. 2-1/다른 관문 승리로 미완료 칸을 밀지 않는다. 지정 관문 재클리어는 멈춘 진행을 복구할 수 있다. 지도도 해당 관문을 선택해 안내한다.
- 오프닝 궁극기 체험은 버튼을 누른 순간 영구 저장하지 않는다. 승리 저장에서 완료하며, 패배 시 다음 관문으로 넘어가지 않는다. 패배 재도전은 이전 패배 저장을 기다리고, 같은 전투 입력의 오프닝/복귀 정보를 보존한다. 화면 종료 후 완료된 이전 요청은 재도전을 시작하지 않는다.
- 로비 안내는 씬 생성이 끝난 첫 프레임에 시작한다. 생성 도중 `isActive()`가 false여서 기존 닉네임 계정의 보급/출격 안내 전체가 생략되던 경로를 바로잡는다.
- 안내는 생성 직후와 매 프레임 대상 위치를 확인한다. 대상이 준비되지 않은 틈에도 기본 화면 입력을 막되 열린 팝업/정보창은 조작할 수 있다. 이동/상태 확인 단계와 정보창을 보는 중에는 편성의 전투 시작 자체도 거절한다. 로비 강화/보급/연구 안내를 진행할 때 이전 출격 메뉴를 자동으로 다시 열지 않는다.
- 저장 구조 변경/SQL 마이그레이션은 없다. 기존 완료 기록과 받은 보급을 보존한다. 지정 관문 재진입이 필요한 중간 저장은 해당 안내부터 이어진다.

검증: 튜토리얼 수정 전체 단위 검사 381개 파일(4,494개 통과, 1개 기존 건너뜀). 패배 저장 경합을 포함한 핵심 139개 검사도 별도로 통과. 타입 검사·생성 서버 번들·일반/QA 빌드·실제 두 빌드의 저장/디버그 격리·출시 고정값 검사도 통과했다. 실제 브라우저에서 연구소 직접 진입 차단, 편성 이동/길게 눌러 정보 확인과 이동·확인 도중 전투 시작 차단, 토리카 일반/즉시 강화, 연구 개방 안내·8개 보급·첫 10회 연구와 서버 저장을 확인했다. 1-5 연구 및 편성 검사는 마지막 수정 후 각각 다시 통과했다. 느린 소프트웨어 렌더링에서 정보창이 실제로 열린 응답을 받은 뒤에도 5초 대기 한도에 걸리는 경우가 있어, 해당 확인은 15초, 연구 안내는 30초로 기다린다.

main 통합: v0.326.1 돌림판 변경을 먼저 보존하고 튜토리얼 수정은 v0.326.2로 올린다. 두 기능의 소스 변경은 겹치지 않으며 생성 서버 번들을 다시 만든다. 통합 전체 단위 검사는 381개 파일, 4,498개 통과·1개 기존 건너뜀이다.
