# 관계 장부

호감도는 **A가 B를 어떻게 보는가**를 −5(증오)~+5(전부를 건다)로 적는다. 0은 무관심이 아니라 경계와 호기심이
반반인 자리다. 숫자는 장면이 **행동으로 보여 준 만큼만** 움직인다(craft 3).

## 1. 상하관계 — 공멸

```
대장  ── 기가노토(궁니르) · 티타노(철갑)        ← 목소리만(7-10)
 └ 부대장 ── 카르                               ← 7장에 풀려남
     ├ 테러조   간부 코마(072) ── 조원 토비·아모(001)·리파
     ├ 회수조   간부 이카닉시아 ── 부간부 아트라 ── 조원 네우리·펄시·미르
     └ 감금조   간부 마가사 · 간부 노아 ── 부간부 라자
```
- 「간부도 조원도 부대장 앞에서는 한 줄」(6-7). 회수조는 실패한 팀을 거두는 일을 맡아 테러조 위에 서는 것처럼 군다.
- 아트라는 회수조지만 코마를 「선배」라 부른다 — 소속보다 오래된 인연.

## 2. 연구원을 향한 시선

| 누가 | 호감 | 무엇으로 보는가 | 변화 |
| --- | --- | --- | --- |
| 토리카 | +5 | 지켜야 할 대장님 | 오프닝부터 |
| 도디 | +5 | 동경하는 대장님 | 오프닝부터 |
| 렉시아 | +4 | 모셔야 할 마스터 | 1-10 합류 |
| 코마 | +1 → +3 | 명령의 대상 → 같은 줄에 선 사람 | 1-10(+1) 2-6서브 「같은 줄」(+2) 3-10 번호를 지움(+3) 7-9 명령 거부 |
| 아모 | −1 → +3 | 위협 → 「더 들어 보고 싶은 사람」 | 2-5(+1) 2-10 따라가겠다(+3) |
| 토비 | 0 → +2 | 잡을 상대 → 다치면 안 되는 사람 | 2-7 문을 뜯음 |
| 리파 | +1 → +2 | 재밌는 상대 → 같이 읽어 줄 사람 | 2-4서브 |
| 이카닉시아 | +2 | 귀한 화물 | 변하지 않음(일부러) |
| 아트라 | +3 | 목록에 적은 사람 | 3-5서브 |
| 네우리 | 0 → +1 | 장부의 한 칸 → 「보류」 | 4-7서브, 7-6서브 |
| 미르 | +1 | 점수 | 3-3서브 「끝까지 뛰었음」 |
| 마가사 | +2 | 귀한 손님(=재료) | 6-3 그릇을 덜어 둠 |
| 노아 | −2 → 0 | 무서운 것 → 곁에 앉아 준 사람 | 6-7서브 |
| 라자 | 0 → +1 | 서열을 다툴 상대 | 5-5, 5-8서브 |
| 카르 | 0 | 필요한 것(손 → 사람 자체) | 7-10 |

## 3. 인연 — 짝으로 움직이는 사람들

| 짝 | 관계 | 핵심 장면 |
| --- | --- | --- |
| 코마 ↔ 아트라 | 선배·후배. 아트라는 코마가 「회수」되는 것을 늦추려 곁에 붙는다 | 3-1, 3-5, 3-5서브 |
| 코마 ↔ 삼인조 | 조장과 조원. 삼인조는 코마 없이 처음으로 스스로 정했다(2-10) | 1-2, 2-10, 4-3 |
| 코마 ↔ 카르 | 명령하는 부대장과 거부하는 072 | 4-10, 5-4, 7-9, 7-10 |
| 코마 ↔ 이카닉시아 | 같은 간부, 서로를 감시 | 3-1, 4-10, 7-5 |
| 토비 ↔ 아모 | 아모가 토비를 챙긴다(「토비가 다치지 않게」) | 2-5, 2-4서브 |
| 마가사 ↔ 노아 | 먹이는 사람과 기다리는 사람 | 6-5, 6-7서브 |
| 라자 ↔ 노아 | 앞에 서는 이유 | 5-8서브, 6-4서브 |
| 라자 ↔ 켄토 | 같은 이유로 앞에 서는 두 탱커 | 6-4서브 |
| 아트라 ↔ 메론 | 이름을 남기는 두 방법(목록과 그림) | 7-6서브 |
| 미르 ↔ 펄시 | 점수판 경쟁 | 3-3서브 |
| 토리카 ↔ 티아 | 소꿉친구, 반짝이 약속 | 1-8 |

## 4. 적대

| 누가 → 누구 | 세기 | 이유 |
| --- | --- | --- |
| 렉시아 → 회수조 | 강 | 마스터를 「모셔 간다」는 말 자체 |
| 마키 → 마가사 | 강 | 연구원을 「재료」라 부름 |
| 리파·토비 → 회수조 | 중 | 묶여 끌려감, 점수로 감시당함 |
| 라자 → 이카닉시아 | 중 | 「거짓말은 여전하군」 |
| 공멸 전체 → 이터널(Garden) | 강 | 만들고 버린 곳(lore) — 연구원 개인에게는 향하지 않는다 |

## 5. 변화 기록

장면을 고칠 때 여기에 한 줄 더한다.

- v0.489.0 — 7-5 이카닉시아가 몰이를 스스로 인정(「아래까지 모셔 왔으니 이제는 서둘러도 된다」). 코마 ↔ 이카닉시아 적대 +1.
- v0.489.0 — 7-9·7-10 자물쇠가 연구원에게 반응. 카르의 시선이 「손」에서 「연구원 자체」로. 코마의 죄책감 갈고리.
- v0.489.0 — 4-10 코마가 연구원에게 「따라오지 마라. 아래는 당신이 올 곳이 아니다」(속삭임). 코마 → 연구원 호감 +1(보호).
- v0.489.0 — 6-5 마가사가 노아를 업고 물러남. 마가사 ↔ 노아 보호 관계 강조.
