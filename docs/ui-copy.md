# 화면 문구 기준

- 한국어 재화명은 **젬**이다. `보석`과 혼용하지 않는다. 다른 언어는 `src/i18n/glossary.ts`의 같은 재화명을 따른다.
- 원정의 **노드**는 고유 용어로 유지한다. 런은 ‘이번 원정’, 서버 정산은 동작에 맞춰 ‘결과 확인/보상 수령’으로 안내한다. API·저장 키와 서버 정산 규칙은 표시 문구에 맞춰 바꾸지 않는다.
- 시스템 확인·오류 안내는 `합니다/해 주세요`, 버튼은 짧은 행동 이름을 쓴다. 캐릭터 대사와 이야기 요약의 말투는 별도다.
- 값 뒤의 한국어 조사는 `{name:을}`처럼 공용 조사 처리를 사용한다. `은(는)`을 병기하거나 `을`을 고정하지 않는다.
- 보상은 재화별 아이콘·수량으로 보여 준다. 서로 다른 재화를 합쳐 `보상 N개`로 부르지 않는다. 지급 전 예상량과 서버가 실제 지급한 양을 구분한다.
- 미지원 로그인 버튼은 현재 구성대로 유지한다. 실제 지원 상태는 기존 안내가 설명한다.

번역은 영어·일본어 표와 `i18n-src` 원고를 함께 수정하고 `scripts/build_translations.py`로 나머지 언어 표를 생성한다. UI 키 누락·자리표시자·고유 용어는 `i18n.test.ts`와 `glossary.test.ts`가 검사한다. 글자가 늘면 기존 글꼴의 원본이나 `patch_font_glyphs.py`로 해당 언어 글꼴도 보충한다. 번역 API를 게임에 추가하지 않는다.
