# 스토리 배경 저작 기준

대사 배경은 인게임 원화와 같은 그림체로, 그 장면의 장소를 보여 준다. 새 게임의 콘셉트 아트처럼 따로 디자인하지 않는다.

- 밝은 연구소는 `background_001.webp`, 도시는 `background_002.webp`, 지하 시설은 `field_ch34.webp`와 `field_ch56.webp`를 직접 참조한다.
- 각진 붓질, 면으로 갈린 명암, 청보라 그림자, 파스텔 조각색과 직선적인 연구 시설 구조를 맞춘다. 가는 장식선·아르누보 곡선·중세풍 첨탑을 새로 더하지 않는다.
- 원화에는 캐릭터를 넣지 않는다. 실제 캐릭터와 공용 대사창을 함께 띄워 대비와 구도를 검수한다.
- `DialogueStory.backdrop`은 시작 장소, `DialogueNode.backdrop`은 사건으로 바뀌는 장소다. 한국어 본문을 검색해서 런타임에 장소를 추측하지 않는다.
- 애착 장도 장소를 명시한다. 실내·수로·도서관·옥상 등을 광장 한 장으로 대신하지 않는다. 밤 장면은 해당 밤 원화를 쓴다.
- 지하 수로에는 맑은 하늘이 그려진 지상 운하를 쓰지 않는다. 같은 물가라도 공간이 다르다.
- 등록은 `backgroundAssets.ts`, 대사 이름과 원화 키의 연결은 `dialogueStageLayout.ts`가 맡는다. 부트 목록에 새 배경을 일괄 추가하지 않는다.

## 사건 전후

| 장면 | 시작 | 사건 뒤 |
| --- | --- | --- |
| 오프닝 열차 폭파 | `train` | `blast` 노드의 섬광 뒤 `wreck` |
| 2-7 압력 격실 구조 | `pressureClosed` | `tear` 노드의 섬광 뒤 `pressureBroken` |

닫힌 철문은 기존 `field_ch56.webp`를 사용한다. 부서진 문은 이 원화를 직접 편집해 벽·배관·조명·시점을 유지한다. 시간대 변형도 같은 원화를 편집하며 새 구도로 다시 그리지 않는다. 폭파 전환은 다음 배경이 준비된 뒤 섬광을 걷는다.

배포 원화는 900×1600 WebP다. 생성 원본이 다른 비율이면 비율을 늘이지 않고 중앙을 기준으로 cover 크롭한다. PNG 원본과 생성 프롬프트는 작업 산출물에 보관한다.
