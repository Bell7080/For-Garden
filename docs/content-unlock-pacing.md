# 콘텐츠 개방 속도 (스테미나 기준)

경험치는 쓴 스테미나에서만 나온다(1:1). 1~9레벨의 요구 경험치를 표로 낮춰 두었다(8·16·26·36·48·60·72·86·100, 10레벨부터는 공식에 이음 배율을 곱해 20레벨에서 합류). 개방 레벨까지 **이론상 최소로 녹여야 하는 스테미나**를 기록한다. 코드 값은 `naturalStaminaToReach`(`src/core/playerLevel.ts`)와 같다.

- 누적 경험치 `cumulativeExpToReach(L)` = Σ `playerExpToNext`
- 빼 주는 것: 시작 스테미나 122(1레벨 상한까지 가득), 레벨업마다 받는 에너지 드링크 60(레벨 L에 닿기까지 L−1병)
- 세지 않는 것: 젬 충전·광고·소탕권·임무/우편 보상 — 모두 더 빠르게 만드는 쪽
- 시간 회복은 5분에 1, 하루 **288**. 보유 상한(120+2L)이 작아 몰아서 쌓아 둘 수 없으므로 하루 최대치는 288(실제로는 접속 간격만큼 덜 찬다)

| 콘텐츠 | 개방 레벨 | 누적 경험치(=스테미나) | 시간 회복으로 채울 몫 | 하루 288 기준 |
|---|---|---|---|---|
| 발굴 | 2 | 8 | 0 | 0.0일 |
| 상점·무역·대작전·현상수배 | 3 | 24 | 0 | 0.0일 |
| 친구 | 4 | 50 | 0 | 0.0일 |
| 교류 | 5 | 86 | 0 | 0.0일 |
| 결투 | 6 | 134 | 0 | 0.0일 |
| 길드 | 7 | 194 | 0 | 0.0일 |
| 레이드 | 8 | 266 | 0 | 0.0일 |
| 원정 | 9 | 352 | 0 | 0.0일 |

**목표**: 진득하게 하는 계정이 하루~이틀 안에 거의 다 연다 — 시작 스테미나와 레벨업 드링크만으로 원정(마지막)까지 열린다. 고고학은 레벨이 아니라 스테이지 1-10 클리어로 연다.

레벨을 옮기면 이 표를 다시 뽑는다(`tests/unit/playerLevel.test.ts`의 개방 속도 검사가 2일 상한을 지킨다).
