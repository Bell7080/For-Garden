# 구독 상품과 배속

집중 연구 멤버십은 해지 전까지 자동 갱신되는 30일 9,900원 구독이며 즉시 젬 3,000과 에너지 드링크 3개, 매일 젬 100을 지급한다. 광고 즉시 수령·기존 소탕 혜택과 전투 3배속을 이용한다. 일반 빌드에서 비구독자는 최대 2배속이며, QA/개발/테스트 빌드는 3배속을 허용한다. 구독 만료 후 저장된 3배속은 2배속으로 보정한다.

젬 전용 월간 연구 후원도 해지 전까지 자동 갱신되는 30일 9,900원 구독에 즉시 젬 3,000, 매일 젬 300을 지급한다. 30회 모두 수령하면 총 젬 12,000이다. 광고 권리는 포함하지 않는다. 구독 탭에서 광고 제거를 맨 위, 젬 구독을 바로 아래에 진열한다.

레이드 패스(6,900원)와 고고학 패스(7,900원)는 동일 상품 ID로 패스·구독 탭 양쪽에 진열한다. 기존 진행 마디 보상은 유지하며, 카드에는 진행 보상 합계를 숨기고 즉시 지급과 일일 지급만 표시한다. 진행 보상은 패스 화면에서 확인한다. 이 두 패스는 자동 갱신 없이 구매 후 30일간만 유지되며 만료 시 일일 지급을 중단한다. 각각 선택 토벌권 1장, 발굴권 1장을 접속한 UTC 날짜마다 우편으로 보낸다. 구매 당일도 받을 수 있고, 접속하지 않은 날은 소급하지 않는다. 우편은 발송 후 7일간 남는다. 상점의 일일 수령 버튼도 같은 우편을 수령하므로 두 탭과 우편함에서 중복 지급하지 않는다.

구독 권리·UTC 일일 수령·발송 우편을 계정 저장의 `serverJournal`에 보존한다. 플랫폼 거래 영수증은 보존 대상에서 제외하지 않으며, 동일 거래를 재검증해도 최초 지급만 수행한다. 운영 스토어에 등록된 가격·상품 유형과 실제 구독 갱신은 서버 결제 검증/스토어 설정에도 동일하게 적용해야 한다. 기존 로컬 서버가 메모리에만 보유하던 활성 구독을 저장에서 복원할 수는 없으며, 운영 서버는 검증된 스토어 영수증으로 권리를 복원해야 한다.

스토어 상품은 광고 제거·젬 구독을 자동 갱신 구독으로, 레이드·고고학 패스를 30일 기간제 비갱신 상품으로 등록한다. 검증된 자동 갱신 거래는 남은 기간 뒤에 30일을 연장하며 기존 권리를 대체한다. 만료를 확인했다고 개발 서버가 결제나 갱신을 흉내 내지는 않는다. 향후 시즌 패스는 시즌별 상품 ID로 등록해 이전 시즌의 구매·보상 기록과 분리한다.

즉시 보상은 스토리 패스 젬 3,000·화석 5·치즈케이크 500, 레벨 패스 젬 3,000·호박석 5·골드 150,000, 레이드 패스 젬 2,000·화석 5·일반 토벌권 5, 고고학 패스 젬 2,500·발굴권 5·호박석 5로 구성한다.

레이드·고고학 패스의 즉시 구성품에는 즉시 딱지를 붙이지 않고 일일 지급에만 매일 표식을 붙인다. 집중 연구 멤버십은 카드와 결제 확인창 모두 광고 제거·전투 3배속 개방 혜택을 표시한다.
