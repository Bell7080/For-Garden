# 충전 재입장 수정 · 업적 확장 QA

최신 main을 `git pull --ff-only origin main`으로 확인한 후 작업했다.

## 수정

- 전투 결과판의 다음 단계·다시 하기·패배 재도전은 누르는 순간 현재 에너지로 판정한다.
- 다음 관문의 비용을 사용하므로 현재 관문과 비용이 다른 경우도 처리한다.
- 에너지가 부족하면 결과판을 유지하고 충전 창을 연다. 충전 후 같은 버튼으로 진행한다.
- 에너지 팝업 우상단 X를 제거하고 하단 중앙의 `돌아가기` 버튼으로 닫는다. 바깥 클릭으로 닫지 않으며 결투 도전권 창의 배치는 유지한다.

## 추가 콘텐츠

기존 업적 ID와 수령 기록을 유지하면서 8개 시리즈, 31개 보상 단계를 추가했다.

| 업적 | 목표 |
| --- | --- |
| 태고를 향하여 | 고대 지층 1 / 10 / 30 / 50 / 100 / 200층 |
| 보통 난이도 전선 | 1 / 10 / 20 / 30개 관문 |
| 어려움 난이도 전선 | 1 / 10 / 20 / 30개 관문 |
| 세공의 완성 | 세공 완료 룬 1 / 3 / 10 / 30개 보유 |
| 특성 연구가 | 특성 룬 1 / 3 / 10 / 30개 보유 |
| 전설의 잠재력 | 전설 특성 룬 1 / 3 / 9개 보유 |
| 완성된 연구팀 | 레벨·돌파·유대 최대 렐릭 3 / 5 / 10명 |
| 빈틈없는 장비 | 룬 3칸을 채운 렐릭 3 / 5 / 10명 |

수식어 6종과 모양이 서로 다른 테두리 3종을 추가했다.

- 태고의 지층: 고대 지층 50층 업적(4단계) 보상 수령.
- 불굴의 월계: 어려움 난이도 전선 4단계 보상 수령.
- 룬의 광채: 세공의 완성 4단계 보상 수령.

고대 지층 최고 기록은 월간 초기화·저장·재접속 후에도 유지된다. 기존 저장에 남은 지층 진행도 소급 반영한다. 이전에 이미 초기화되어 저장에 남지 않은 과거 기록은 복원하지 않는다. 룬 보유 목표는 현재 보유 수를 기준으로 하며 이미 수령한 보상은 다시 지급하지 않는다.

지원 언어 12개(한국어 포함)에 신규 문구를 반영했다. 전체 업적 젬 보상은 기존 예산 15,000개 이내다.

## 검증

- TypeScript `tsc --noEmit` 통과.
- Vite test 모드 빌드 통과. 기존 청크 크기·동적 import 경고는 남아 있다.
- 결과판·업적·프로필·레벨 관련 단위 테스트: 62개 통과.
- 번역·데이터 문구·업적 목록 관련 테스트: 45개 통과(일부 업적 테스트 중복 포함).
- 지층 시즌·지층 서버·저장·프로필·에너지 관련 테스트: 108개 통과.
- 실제 Edge Chromium 브라우저 테스트: 3개 통과.
  - 에너지 0 → 드링크 사용으로 60 충전 → 같은 결과판의 다음 단계 → 편성 진입.
  - 업적 목록 열기 및 분류 전환.
  - 업적 테두리 미리보기 → 장착 → 저장된 frameId 확인.

에너지 팝업 하단 버튼 반영 후 타입 검사·빌드와 관련 테스트 46개를 통과했다. 브라우저 재입장 검사는 이전 X 위치를 눌러도 팝업이 유지되고 하단 `돌아가기`로 닫히는 조건을 포함한다.

온라인 운영 계정이나 배포 환경에서 검증한 결과는 아니다.
